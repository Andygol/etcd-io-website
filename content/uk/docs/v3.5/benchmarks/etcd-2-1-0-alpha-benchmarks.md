## Фізичні машини {#physical-machines}

Тип машини GCE n1-highcpu-2

- 1x виділений локальний SSD, змонтований у /var/lib/etcd
- 1x виділений повільний диск для ОС
- 1.8 ГБ памʼяті
- 2x ЦПУ
- версія etcd 2.1.0 alpha

## Кластер etcd {#etcd-cluster}

3 учасники etcd, кожен працює на окремій машині

## Тестування {#testing}

Запустіть іншу машину та використовуйте [hey HTTP benchmark tool][hey], щоб надсилати запити до кожного учасника etcd. Перевірте [benchmark hacking guide][hack-benchmark] для детальних інструкцій.
